🛠️ Architecture & Technical Stack
The store is built on a high-performance WordPress/WooCommerce platform utilizing custom HTML/CSS blocks injected via Elementor or page builders, ensuring complete autonomy from clunky default themes while preserving speed and visual elegance.
Key Technical Implementations:
1. Header & Footer Isolation:
Default WordPress headers (#masthead, .site-header, etc.) and system wrappers are programmatically overridden and hidden using high-specificity CSS (!important).
A custom, responsive 4-column luxury footer is integrated directly into the layout files across all core pages.
2. Dark-Mode Aesthetics:
Strict adherence to a luxury dark palette (#020202 background, #d4af37 gold accents, and #ffffff typography using Cinzel and Plus Jakarta Sans fonts).
3. Full-Width Viewport Scaling:
Custom CSS box-sizing and negative margins (margin-left: -50vw) force full-screen edge-to-edge alignment on desktop and mobile devices.
